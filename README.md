# V-Stream Vault 影音媒體庫與極速播放器

專為極致視聽體驗量身打造的現代化影片媒體庫與全功能播放器。全站採用**純向量 SVG 元素**、**深色劇院質感設計**，以及**本機 IndexedDB + 即時串流快取技術**，實現零延遲的極速上傳與秒開播放。

---

## 🌟 核心特色與改版重點

### 1. 開啟首頁即為「影音媒體庫」
- 沒有冗餘宣傳首頁，打開網頁直接進入純粹、高效能的**影音媒體庫 (Video Library)**。
- 頂部整合高質感微型統計列（媒體庫總部數、累積總時長、本機已用容量）。
- 支援「網格卡片」與「橫向清單」檢視模式切換。
- 支援分類標籤即時篩選（全部、動畫、電影、音樂 MV、教學、生活記錄）與多維度排序（最新新增、片長、大小、片名）。
- 即時全站關鍵字模糊搜尋、多選批次刪除功能。

### 2. 彈窗式極速上傳 (支援完整自訂屬性)
點擊導覽列「上傳影片」按鈕立即彈出自訂上傳視窗，提供完整設定：
- **極速檔案拖放/瀏覽**：支援 MP4、WebM、MKV、MOV 等主流格式，瞬間生成 Object URL 並即時解析規格（4K UHD / 1080p FHD 等）與片長大小。
- **自訂影片名稱**：自動預填檔案名稱，支援任意重命名。
- **自訂分類與簡介**：下拉選擇影片分類，並可填寫多行備忘或劇情簡介。
- **多功能縮圖自訂**：
  - **智慧自動抽幀**：影片載入時自動在第 1 秒抽取畫面。
  - **影格時間軸拉桿**：可任意拖曳滑動至影片特定秒數，即時重新擷取該幀作為封面。
  - **自訂圖片上傳**：可直接上傳本機 JPG / PNG / WebP 圖片作為專屬封面圖。
- **字幕檔案支援 (.vtt / .srt)**：
  - 支援選取上傳 SRT / WebVTT 字幕檔，系統自動解析對白時間碼與內容。
  - 播放時字幕與視訊幀精準同步，並可透過 CC 按鈕一鍵開啟/關閉。

### 3. 嚴格復刻專業極簡播放器 (完全吻合參考截圖)
- **左上方影片標題與頂部漸層遮罩**：深邃自然的暗角過渡，凸顯影片主體。
- **純 SVG 控制器群組**：
  - 播放 / 暫停按鈕（三角 / 雙槓符號）
  - 快退 10 秒 / 快進 10 秒（雙三角帶垂直桿）
  - 時間碼顯示：採用 `1:05:06` / `1:57:21` 高精度時間碼格式
  - **天藍色進度條與圓形拖曳控制點**：懸停時間預覽氣泡、滑動拖曳與緩衝區可視化
  - **字幕 (CC) 開關**：開啟時以高亮青藍色提示，畫面中央下方同步渲染對白字幕。
  - 音量調節滑桿、畫中畫 (PiP)、設定齒輪（0.5x~2.0x 倍速、畫面填滿比例設定、循環播放）與四角全螢幕括弧。
- **鍵盤快捷鍵**：
  - `Space` / `K`：播放 / 暫停
  - `←` / `→`：快退 / 快進 5 秒
  - `↑` / `↓`：音量增減 10%
  - `C`：字幕開關切換
  - `F`：全螢幕切換
  - `M`：靜音切換
  - `Esc`：關閉播放器

---

## 🚀 快速開始使用

1. 直接使用現代瀏覽器（Google Chrome、Microsoft Edge 等）雙擊打開 `index.html` 即可立即運作。
2. 初次開啟時媒體庫為空，點擊右上角「上傳影片」按鈕即可加入影片。
3. 點擊右上角「上傳影片」按鈕即可彈出對話框，體驗自訂影片名稱、簡介、封面縮圖與字幕的極速入庫流程！
